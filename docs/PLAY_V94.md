# BLUE ALERTS V94 — accès au jeu

La version jouable publiée par le workflow GitHub Pages est construite depuis :
- `BLUE_ALERTS_v94_ASSET_INTEGRATION.html` (entrée web)
- `game-data/models/blue-alert-models.js` (bibliothèque de modèles 3D)

Le déploiement publie le jeu sous le nom `index.html` et conserve le chemin relatif des modèles 3D. Le navigateur doit autoriser WebGL et l'accès réseau au CDN Three.js.

Cette note est conservée dans le dépôt pour documenter la cible du déploiement V94. Elle ne remplace pas un test réel du jeu dans Chrome Android.
