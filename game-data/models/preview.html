BLUE ALERT / Atelier de modèles 3D

Kit procédural Three.js · sans API payante
Glisser : orbiter · molette : zoom · clic droit : déplacer

Char de combat

Maillage 3D original composé de blindage, chenilles, roues, tourelle pivotante, canon, trappes et marquage d'équipe.

État : modèles procéduraux en géométrie Three.js. Le code est conçu pour être appelé depuis le moteur web du jeu.

Commandes :
Glisser pour tourner
Molette pour zoomer
Clic droit pour déplacer la caméra
